# Shelton Catalogue System

A full-stack catalogue management system with a public catalogue interface, admin panel, and backend API.

---

## 📦 Project Overview

This project includes:

- Public Catalogue Website
- Admin Dashboard
- Backend API
- Swagger API Documentation
